# Voice auditions

Modern synthesized male voice auditions, not historical recordings. Same opening-script excerpt with each voice at natural speed. The full film carries factual corrections for the supplied advocacy text; these excerpts test vocal delivery only.

- am_michael: American English
- bm_george: British English

Kokoro-82M model and English voice tensors: Apache-2.0. See research/kokoro-rights.md and research/kokoro-license-evidence.json. ONNX runtime wrapper: MIT. No audio-output restriction stated by the publisher.
